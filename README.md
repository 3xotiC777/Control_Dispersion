# Ruta Compacta

Aplicación web para asignar titulares y suplentes por cercanía geográfica, respetando el forecast diario por **MT FINAL**.

La aplicación publicada está disponible en `https://3xotiC777.github.io/Control_Dispersion/`.

## Uso

1. Carga la base de puntos Excel y el forecast.
2. Presiona **Calcular planificación**.
3. Usa la búsqueda de MT FINAL y los botones de días para revisar el mapa y la tabla.
4. Selecciona un punto en el mapa si necesitas moverlo de día.
5. Descarga el Excel resultante.

El despliegue de GitHub Pages se ejecuta automáticamente al actualizar la rama `main`.
